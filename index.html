Configuração do Google Sheets

🔓 ACESSO PERMITIDO
Encontre na URL da sua planilha: docs.google.com/spreadsheets/d/ID_DA_PLANILHA/edit

💾 Backup de Configuração

As configurações são automaticamente salvas na planilha para recuperação em caso de troca de dispositivo ou limpeza do navegador.

📋 Instruções de Configuração Detalhadas

  1. Crie uma planilha Google
    • Acesse sheets.google.com
    • Crie uma nova planilha em branco
    • Na URL, copie o ID que aparece após /d/ e antes de /edit
  2. Configure o Google Apps Script
    • Acesse script.google.com
    • Clique em "Novo projeto"
    • Cole o código do Google Apps Script fornecido
    • Na linha 2, substitua SUA_PLANILHA_ID_AQUI pelo ID da sua planilha
    • Salve o projeto (Ctrl+S)
  3. Implante a aplicação
    • Clique em "Implantar" → "Nova implantação"
    • Tipo: Aplicação Web
    • Executar como: Eu
    • Acesso: Qualquer um
    • Copie a URL fornecida
  4. Configure o sistema
    • Cole a URL do script no campo acima
    • Cole o ID da planilha no campo correspondente
    • Clique em "Salvar Configuração"
    • Teste a conexão

✅ Pronto! Os dados serão salvos automaticamente na sua planilha.
